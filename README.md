⚠️ Дисклеймер

SSMaker является авторской программой, созданной Foxoros.

Программа и её содержимое не предназначены для распространения, копирования или передачи третьим лицам без разрешения создателя — Foxoros.

Для начала установки:

Скачайте ZIP-архив SSMaker.
Разархивируйте ZIP-архив в удобное место.
Откройте распакованную папку.
Запустите SSMakerSETUP.exe
Следуйте инструкциям установщика.

Не запускайте SSMakerSETUP.exe непосредственно из ZIP-архива — сначала необходимо полностью разархивировать архив.
